## Patterns observed across these projects

- Local Impact winners name a concrete local user and place (Arequipa forests, non-experts in Brazil).
- Several winners package hard EO data for non-experts rather than add new ML (G.R.O.W., Landsat Connect, SARchasm).
- Fire entries that got furthest had something clickable: a live deployment (Prometheus), a runnable notebook (SARchasm), a site plus video (Phoenix Eye).
- Entries citing literature or deriving a correction (UMChallengers, SARchasm) are the ones with explicit scientific grounding.
